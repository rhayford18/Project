# Project
Checkers Game (Pygame)

# Overview
This project is a digital implementation of the classic game Checkers, built using Python and the Pygame library. The game supports two players taking turns on the same computer and includes standard checkers rules such as diagonal movement, capturing pieces, and king promotion. A turn-based timer is also included to track how long each player takes during the game.
This project was developed as part of a computer science course to practice object-oriented programming, game loops, and event handling in Python.


# Features
8x8 checkers board
Two-player local gameplay
Diagonal movement and piece capturing
King pieces with enhanced movement
Turn-based timer
Visual board and pieces using Pygame
Mouse-based piece selection and movement
Technologies Used
Python 3
Pygame
